이 블로그는 Windows 98의 향수를 담아 제작된 개인 공간입니다.
단순히 정보를 전달하는 것을 넘어, 인터랙티브한 경험을 통해
저의 개발 여정과 생각들을 공유하고자 합니다.
notepad의 데이터는 sessionStorage에 저장됩니다.

폴더 안내:
- [article]: react-notion-x를 활용하여 Notion에 작성된 기술 관련 글들을 게시합니다.
- [about me]: 저의 포트폴리오와 개인적인 생각, 철학 등을 담은 글들을 게시합니다.
- [Computer / Document]: Windows 98 테마의 핵심 요소로, 파일 탐색의 재미를 위해 구성되었습니다.

사용된 기술 (Tech Stack):
- Framework: Next.js 16 (App Router)
- UI Library: React 19, 98.css, TailwindCSS
- State Management: Zustand
- Content Integration: Notion API, react-notion-x
- Window System: Custom Hook 기반의 드래그/리사이즈/Z-index 관리 시스템

조작 방법:
- [아이콘 실행]: 바탕화면의 아이콘을 더블 클릭하면 해당 앱이나 폴더가 열립니다.
- [창 이동/크기 조절]: 창의 타이틀 바를 드래그하여 이동하거나, 창의 테두리를 잡아 크기를 조절할 수 있습니다.
- [창 최소화/닫기]: 우측 상단의 버튼을 통해 창을 최소화하거나 닫을 수 있습니다.
- [멀티태스킹]: 여러 창을 동시에 띄워두고 자유롭게 오가며 콘텐츠를 즐겨보세요.
